# Python Basics: Statistics Calculator 📊

This repository contains a Python script that calculates basic statistical measures. It's part of my journey to master Python for **AI and Data Science**.

### 🛠️ Features
- Calculates **Mean** (Average)
- Calculates **Variance**
- Calculates **Standard Deviation** using the `math` library

### 🚀 How to Run
1. Run the script in any Python environment (like Pydroid 3 or VS Code).
2. Enter the value of **N** (how many numbers you have).
3. Input the numbers one by one.
